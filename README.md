# attnvis

Lightweight attention visualisation tools for learning, debugging, and explaining Transformer models.

## Goals
- Understand attention mechanics visually
- Support multi-head self-attention
- Minimal dependencies
- Notebook-friendly

## Status
🚧 Work in progress — starting from first principles (Attention Is All You Need).

## Planned
- Scaled dot-product attention visualisations
- Multi-head attention heatmaps
- Token-level introspection
